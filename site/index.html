X70 head: install and update

Build BUILD_NUMBER. Use this page for the first install over USB. After that the head checks GitHub by itself and updates both boards while it is idle (switch on the head page: Update and Wi-Fi).

First install (USB)

  1. Use Chrome or Edge on a computer (not a phone).
  2. Plug the board in with a USB cable.
  3. Click the button for that board and pick its port.
Head (ESP32 in the box on the tripod head)

Joystick box (ESP32 in the Vidpro controller)

When asked, choose Erase device for a first install (this clears saved Wi-Fi, limits and presets). If it reports an error at the very end, unplug the USB, plug it back in and check whether the board's own Wi-Fi appears before retrying.

After installing

  1. Each board makes its own Wi-Fi: X70-Head and X70-Joystick, password x70head123.
  2. Join it, open http://192.168.4.1 (for the head: http://192.168.4.1/wifi) and enter your Wi-Fi.
  3. Head page afterwards: http://x70head.local
